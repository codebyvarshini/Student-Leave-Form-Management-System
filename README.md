# Student Leave Form Management System

## About the Project
The Student Leave Form Management System is a web-based application developed to simplify the process of submitting and managing student leave requests.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS

## Features
- Student leave form submission
- View student leave details
- Admin can manage leave requests
- Store and retrieve leave records using a database

## Database Setup
1. Create a MySQL database named `leavedb`.
2. Import the `leavedb.sql` file using phpMyAdmin.
3. Copy the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL.
5. Open the project in your browser.
